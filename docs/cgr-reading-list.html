논문끼리 연결

주황색 칸이 랩 논문, 청록색이 내 프로젝트. 위쪽은 모션 데이터를 흉내 내는 흐름, 아래쪽은 보상만으로 걷는 흐름이야. ASE → PhysicsFC는 "미리 학습한 동작 임베딩 위에 기술별 정책을 올린다"는 구조적 연결이고, 원 논문이 정확히 어떤 임베딩 모델을 썼는지는 본문에서 확인해.

랩 논문

PhysicsFC: Learning User-Controlled Skills for a Physics-Based Football Player Controller

이번 주말

Minsu Kim, Eunho Jung, Yoonsang Lee · SIGGRAPH 2025 · arXiv 2504.21216 · 프로젝트 페이지

사용자가 키 입력으로 조종하는, 물리 시뮬레이션 속 축구선수 캐릭터. 드리블·트래핑·이동 같은 기술을 따로 학습하고 매끄럽게 이어 붙인다.

푸는 문제

물리 기반 캐릭터는 자연스럽지만 조종하기 어렵다. 게임처럼 사용자가 실시간으로 명령을 바꿔도 공을 다루는 기술들이 끊김 없이 이어져야 한다.

핵심 아이디어
  • 미리 학습된 물리 기반 동작 임베딩 모델 위에, 기술별 정책(Dribble, Trap, Move)이 잠재 변수를 출력한다. 관절을 직접 움직이는 게 아니라 "어떤 동작을 할지"를 고른다.
  • 기술마다 보상을 따로 설계: Dribble은 맞춤 보상, Trap은 2단계 보상 + 공의 포물선 운동을 이용한 초기화, Move는 DEGCL(Data-Embedded Goal-Conditioned Latent Guidance) — 모션 데이터에 담긴 목표치를 보상에 함께 반영.
  • STI(Skill Transition-Based Initialization): 학습할 때 다른 기술에서 넘어오는 상태로 시작시켜서, 기술 전환이 부드러워지게 한다.
  • 유한 상태 기계(FSM)가 사용자 입력을 보고 어떤 기술을 쓸지 고른다.
내 프로젝트와

키보드 조종 데모가 "사용자 조작"의 축소판이야. 내 Ant는 명령이 250스텝마다 바뀌면서 전환을 배우는데, PhysicsFC는 전환을 STI로 명시적으로 다뤄. 메일에서 "다음엔 전환 품질을 측정해보고 싶다"고 이어 쓰기 좋은 지점.

읽을 때 볼 것

전체 구조 그림(어떤 정책이 무엇을 출력하는지), STI가 왜 필요한지, Move 정책의 DEGCL 보상 식. 시뮬레이터·알고리즘·코드 공개 여부는 초록에 없으니 본문에서 확인.

FreeMusco: Motion-Free Learning of Latent Control for Morphology-Adaptive Locomotion in Musculoskeletal Characters

이번 주말

Kim, Yoonsang Lee · SIGGRAPH Asia 2025 · arXiv 2511.14205 · 프로젝트 페이지

모션캡처 없이, 근육으로 움직이는 캐릭터가 걷는 법을 스스로 배운다. 몸 형태가 달라도 적응한다.

푸는 문제

근골격 캐릭터는 근육이 많아 제어가 어렵고, 보통은 모션캡처 데이터에 기대서 학습한다. 데이터가 없는 몸(새로운 생물, 바뀐 체형)에는 쓸 수가 없다.

핵심 아이디어
  • 모델 기반 RL로 잠재 표현과 제어 정책을 함께 학습한다.
  • 보행 목표 = 제어 + 균형 + 생체역학 항. 한 시점이 아니라 시간 창 전체에서 평균 낸 손실로 시뮬레이션 상태와 목표 상태를 비교한다.
  • 목표 자세와 에너지 수준을 랜덤화해서 다양한 걸음걸이를 얻는다.
  • 다운스트림 태스크: 목표 지점 이동, 경로 추종. 사족형 "Chimanoid"와 인간형 캐릭터에서 실험.
내 프로젝트와

가장 가까운 논문이야. 모션 데이터 없이 보상만, 에너지 수준을 입력으로 받아 동작이 달라지게, 경로 추종으로 확인 — 세 가지 다 내 Ant 프로젝트에 들어 있어. 차이는 내 쪽이 모델 없는 PPO + 토크 제어 + 단순한 사족 로봇이라는 점. 이 차이를 README "한계" 칸에 정직하게 써두면 좋아.

읽을 때 볼 것

"에너지 수준"을 어떻게 정의하고 정책에 넣었는지(내 방식과 비교), 시간 평균 손실을 왜 썼는지, 왜 모델 기반 RL을 골랐는지.

이번 주말 배경 논문

Learning to Walk in Minutes Using Massively Parallel Deep Reinforcement Learning

이번 주말

Nikita Rudin, David Hoeller, Philipp Reist, Marco Hutter · CoRL 2021 · arXiv 2109.11978

GPU 한 장에서 수천 개 환경을 동시에 돌려, 사족 로봇이 평지는 몇 분, 울퉁불퉁한 지형은 20분 만에 걷게 만들고 실제 로봇에도 옮겼다.

푸는 문제

로봇 보행 RL은 학습이 며칠씩 걸렸다. 시뮬레이션을 GPU에서 대량 병렬로 돌리면 학습 시간을 얼마나 줄일 수 있나?

핵심 아이디어
  • Isaac Gym으로 수천 개 로봇을 한 GPU에서 동시에 시뮬레이션, PPO 하이퍼파라미터를 대규모 병렬에 맞게 조정.
  • 로봇은 목표 속도 명령(앞뒤·좌우 속도, 회전 속도)을 따르도록 학습. 추종 보상은 exp(−오차²/σ) 형태.
  • 게임처럼 잘하면 더 어려운 지형으로 보내는 지형 커리큘럼.
  • ANYmal 실제 로봇에 그대로 배포(sim-to-real). 코드 공개(legged_gym).
내 프로젝트와

내 보상의 속도 추종 항 exp(−‖v − v_cmd‖² / 0.25)이 이 논문 형태를 따랐어. 차이: 이 논문은 회전 속도도 명령하고 보상 항이 훨씬 많아(관절 가속도, 발 공중 시간 등). 그 표를 보면서 "내 걸음이 부자연스러운 이유"를 찾아볼 수 있어.

읽을 때 볼 것

보상 항 목록 표, 명령 샘플링 방식, 지형 커리큘럼. 실제 로봇과 군용 무인 지상로봇 쪽 관심과도 바로 이어지는 논문.

Proximal Policy Optimization Algorithms

이번 주말

John Schulman, Filip Wolski, Prafulla Dhariwal, Alec Radford, Oleg Klimov · 2017 · arXiv 1707.06347

정책을 한 번에 너무 많이 바꾸지 않도록 "잘라내기(clipping)"를 해서, 간단하면서도 안정적으로 학습하는 정책경사 알고리즘.

푸는 문제

정책경사는 업데이트 한 번이 너무 크면 정책이 망가진다. TRPO는 이걸 막지만 구현이 복잡하다. 더 단순하게 같은 효과를 낼 수 없나?

핵심 아이디어
  • 새 정책/옛 정책의 확률 비율 r을 [1−ε, 1+ε]로 잘라서(보통 ε = 0.2) 목적함수를 만든다. 비율이 범위를 벗어나면 더 밀어붙여도 이득이 없다.
  • 그래서 같은 데이터로 미니배치 학습을 여러 에폭 반복해도 안전하다 → 데이터 효율이 좋아진다.
  • 이점(advantage)은 GAE로 추정하고, 가치 함수와 함께 학습(actor-critic).
내 프로젝트와

train.py의 clip_range=0.2, n_epochs=10, gae_lambda=0.95가 전부 이 논문에서 나온 설정이야. 학습 로그의 clip_fraction(잘린 비율)과 approx_kl(정책이 얼마나 바뀌었나)도 이걸 알면 읽혀.

읽을 때 볼 것

clipped surrogate objective 식과 그림, Algorithm 1. 수식을 다 따라가기보다 "왜 자르는지"만 확실히 이해하면 충분해.

인턴 시작 전까지

Learning Symmetric and Low-Energy Locomotion

인턴 전

Wenhao Yu, Greg Turk, C. Karen Liu · SIGGRAPH 2018 · arXiv 1801.08093

모션캡처 없이도 RL로 좌우 대칭이고 에너지를 아끼는, 자연스러운 걸음을 만들 수 있다.

푸는 문제

보상만으로 학습한 보행은 다리를 질질 끌거나 비대칭인 이상한 걸음이 되기 쉽다. 모션 데이터 없이 이걸 고칠 수 있나?

핵심 아이디어
  • 정책 손실에 좌우 대칭 손실을 추가: 거울상 상태에서는 거울상 행동을 하도록.
  • 커리큘럼 학습: 처음엔 가상의 보조 힘으로 넘어지지 않게 도와주고, 점점 줄여간다.
  • 저에너지 보상과 함께 이족·사족 등 여러 몸에 적용.
내 프로젝트와

내 Ant의 걸음이 이상해 보이면 그 이유와 해법이 여기 있어. 다음 단계로 "대칭 손실을 넣어봤다"를 해보면 좋은 확장 실험이 돼.

읽을 때 볼 것

대칭 손실 정의, 보조 힘 커리큘럼, 결과 영상.

DeepMimic: Example-Guided Deep Reinforcement Learning of Physics-Based Character Skills

인턴 전

Xue Bin Peng, Pieter Abbeel, Sergey Levine, Michiel van de Panne · SIGGRAPH 2018 · arXiv 1804.02717

모션캡처 클립 하나를 물리 시뮬레이션 캐릭터가 RL로 따라 하게 해서, 백덤블링 같은 고난도 동작까지 재현했다.

푸는 문제

애니메이션은 자연스럽지만 물리를 무시하고, 물리 기반 제어는 정확하지만 동작이 어색하다. 둘을 합칠 수 있나?

핵심 아이디어
  • 보상 = 참조 동작과의 모방 보상(관절 자세·속도, 손발 위치, 무게중심) + 과제 보상(목표 방향 걷기, 공 던지기 등).
  • Reference State Initialization: 클립의 아무 시점에서나 에피소드를 시작 → 어려운 구간도 고르게 배운다.
  • Early Termination: 넘어지면 바로 종료 → 쓸데없는 데이터를 줄인다.
내 프로젝트와

내 Ant도 넘어지면 에피소드가 끝나는데(Early Termination), 그게 왜 학습에 중요한지 이 논문 실험이 보여줘. PhysicsFC의 STI는 RSI의 "기술 전환 버전"이라고 보면 이해가 쉬워.

읽을 때 볼 것

모방 보상 식, RSI·ET를 뺐을 때 결과 비교.

AMP: Adversarial Motion Priors for Stylized Physics-Based Character Control

인턴 전

Xue Bin Peng, Ze Ma, Pieter Abbeel, Sergey Levine, Angjoo Kanazawa · SIGGRAPH 2021 · arXiv 2104.02180

어떤 클립을 따라 할지 정해주지 않아도, 판별기가 "모션 데이터처럼 보이는지"를 점수로 줘서 스타일을 배운다.

푸는 문제

DeepMimic은 상황마다 따라 할 클립을 골라줘야 해서, 여러 동작을 섞어 쓰기 번거롭다.

핵심 아이디어
  • GAN처럼 판별기가 캐릭터의 상태 전이가 모션 데이터셋에서 나온 것 같은지 판단 → 그 점수를 스타일 보상으로 사용.
  • 스타일 보상 + 과제 보상을 더해서, "과제는 해내면서 데이터처럼 자연스럽게" 움직이게 한다.
내 프로젝트와

내 Ant는 스타일 보상이 없어서 걸음이 어색할 수 있어. "모션 데이터가 있다면 AMP식 스타일 보상을 붙일 수 있다"가 자연스러운 다음 단계.

읽을 때 볼 것

판별기 보상을 어떻게 만드는지, 과제 보상과 섞는 비율.

ASE: Large-Scale Reusable Adversarial Skill Embeddings for Physically Simulated Characters

인턴 전

Xue Bin Peng, Yunrong Guo, Lina Halper, Sergey Levine, Sanja Fidler · SIGGRAPH 2022 · arXiv 2205.01906

여러 기술을 하나의 잠재 공간에 미리 학습해두고, 새 과제에서는 상위 정책이 "어떤 잠재 벡터를 줄지"만 배운다.

푸는 문제

새 과제마다 처음부터 학습하는 건 비효율적이다. 기술을 한 번 배워두고 재사용할 수 없나?

핵심 아이디어
  • 저수준 정책: 잠재 벡터 z를 받아 동작을 만든다. 대량의 모션 데이터로 적대적 모방(AMP식) + 비지도 기술 발견으로 미리 학습.
  • 상위 정책: 과제(목표 지점 가기, 타격 등)를 위해 z만 출력. 저수준 정책은 고정.
  • 대규모 병렬 시뮬레이션으로 학습.
내 프로젝트와

내 경로 추종도 "상위 로직이 명령을 주고 하위 정책이 걷는" 2단 구조야. 차이는 내 명령은 사람이 정한 속도 값이고, ASE는 학습된 잠재 벡터라는 것. PhysicsFC가 "동작 임베딩 위에 기술별 정책"을 올리는 구조를 이해하려면 이 논문이 열쇠야.

읽을 때 볼 것

저수준/상위 정책 구조 그림, 잠재 공간을 왜 구(sphere) 위에 두는지.

MaskedMimic: Unified Physics-Based Character Control Through Masked Motion Inpainting

인턴 전

Chen Tessler, Yunrong Guo, Ofir Nabati, Gal Chechik, Xue Bin Peng · SIGGRAPH Asia 2024 · arXiv 2409.14393

일부 조건만 주면(머리 위치만, 키프레임 몇 개만, 텍스트만) 나머지 전신 동작을 채워 넣는 하나의 범용 컨트롤러.

푸는 문제

과제마다 컨트롤러를 따로 만드는 대신, 다양한 입력 형태를 하나의 정책으로 처리할 수 없나?

핵심 아이디어
  • 제어를 모션 인페인팅으로 본다: 조건 중 일부를 가리고(mask) 나머지를 채우는 문제.
  • 먼저 전신 동작 추적 정책을 학습하고, 이를 가려진 입력을 받는 정책으로 증류(distillation)한다.
  • VR 추적, 키프레임, 텍스트, 물체 상호작용을 하나의 정책으로.
